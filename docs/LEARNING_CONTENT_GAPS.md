# Learning content: evidence and review gaps

Status: editorial review list for the first public version.

The source links currently shown in the app were checked against DOI, PubMed or the publishing institution. That verifies that the referenced publication exists; it does **not** mean every practical exercise in a topic has been directly tested. The actions and reflection questions are deliberately labelled as editorial exercises where the available source only supports the broader mechanism.

## Review by topic

## Source and licence checks

- IPIP-NEO-120 source and public-domain status should receive one final product/legal review before a large public launch. The current app links to Johnson (2014) and does not reproduce proprietary NEO PI-R material.
- The `@bigfive-org/questions` language files and package licence should be recorded in a future `THIRD_PARTY_NOTICES` file.
- The result library contains static package-owned text. TraitBridge now renders its own neutral contextual interpretation and uses package data only for facet titles/scores; no package HTML is injected.
- Book titles, author names and short original editorial descriptions are metadata/editorial commentary. No covers, publisher blurbs, quotations or long excerpts are used.
- German book titles and author metadata should be checked against current publisher catalogues before commercial publication.
- The “Highly Sensitive Person” entry must remain labelled as a popular framework, not a diagnosis or established Big Five construct; remove it if the editorial review cannot support that distinction.
